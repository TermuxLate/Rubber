# Termux Guide - Полное руководство по командам

Современный веб-сайт с полным справочником по командам Termux, адаптированный для русскоязычных пользователей.

## 🌟 Особенности

- **Полный справочник команд** - Более 50 команд с подробными описаниями
- **Адаптивный дизайн** - Оптимизирован для всех устройств и разрешений экрана
- **Интерактивный поиск** - Быстрый поиск команд по названию и описанию
- **Фильтрация по категориям** - Основные, пакеты, файлы, сеть, система
- **Модальные окна** - Подробная информация о каждой команде
- **Копирование команд** - Одним кликом скопировать команду в буфер обмена
- **Современный UI/UX** - Красивый и интуитивный интерфейс
- **Русскоязычный контент** - Полностью на русском языке

## 🚀 Быстрый старт

### Требования
- PHP 7.4 или выше
- Веб-сервер (Apache, Nginx, или встроенный PHP сервер)
- Современный браузер с поддержкой ES6

### Установка

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/your-username/termux-guide.git
cd termux-guide
```

2. **Запустите локальный сервер:**
```bash
# Используя встроенный PHP сервер
php -S localhost:8000

# Или используя Python (если установлен)
python -m http.server 8000
```

3. **Откройте браузер:**
```
http://localhost:8000
```

## 🌐 API

### Endpoints

#### GET /api/commands.php
Получить список команд

**Параметры:**
- `action=list` - Список команд
- `action=categories` - Список категорий
- `action=random` - Случайные команды
- `action=popular` - Популярные команды
- `category` - Фильтр по категории
- `search` - Поисковый запрос
- `limit` - Лимит результатов

**Пример:**
```bash
curl "http://localhost:8000/api/commands.php?action=list&category=package&limit=10"
```

#### POST /api/commands.php
Поиск и предложения

**Тело запроса:**
```json
{
  "action": "search",
  "query": "python",
  "category": "package",
  "limit": 10
}
```

## 🛠️ Разработка

### Добавление новых команд

1. Отредактируйте файл `assets/js/script.js`
2. Добавьте новую команду в массив `commandsData`
3. Обновите API в `api/commands.php` если необходимо

### Структура команды
```javascript
{
    name: "название команды",
    category: "категория",
    description: "описание",
    syntax: "синтаксис",
    examples: ["пример1", "пример2"],
    details: "подробное описание"
}
```

### Кастомизация стилей

Основные CSS переменные в `assets/css/style.css`:
```css
:root {
    --primary-color: #00d4aa;
    --secondary-color: #667eea;
    --accent-color: #f093fb;
    --dark-color: #1a1a1a;
    --light-color: #ffffff;
    /* ... */
}
```
